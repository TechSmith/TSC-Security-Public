# Security Advisory: Brotli Library Vulnerability (CVE-2026-111497)

**Status:** Remediation in Progress  
**Last Updated:** 02-Nov-2026

## Summary

TechSmith is aware of CVE-2026-111497, a security vulnerability affecting the Brotli compression library, commonly known as Brotli2Shell or Node2Shell.

TechSmith's desktop applications incorporate the Brotli library as a transitive dependency, our web hosted services are not at risk.

At this time, TechSmith is not aware of any exploitation of this vulnerability involving its products. Security fixes are being incorporated in accordance with our dependency patching practices.

## Products Incorporating Brotli and Remediation Status

| Product | Platform | Version Containing Fix | Release Status |
|---|---|---|---|
| Camtasia Editor</br>(formerly Camtasia) | Windows | 2026.2.5 | Expected 03-Nov-2026 |

| Camtasia Snagit</br>(formerly Snagit) | Mac | 2027.0.0 | TBD |
| Camtasia Audiate | Windows &amp; Mac | 2027.0.0 | Released 29-Oct-2026 |

## Customer Impact and Recommended Action

TechSmith has not identified any exploitation of CVE-2026-111497 involving its products. As a precaution, customers should avoid opening or importing fonts and project files from untrusted sources.

Customers are encouraged to update to the fixed versions listed above as they become available.

No action is required for customers using TechSmith's hosted services.
